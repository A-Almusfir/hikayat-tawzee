# حكاية توزيع

> افهم الحكاية… يثبت القانون.

موقع عربي تفاعلي يساعد طلاب المقررات الجامعية التمهيدية على فهم ستة توزيعات احتمالية وحفظها والتمييز بينها:
برنولي، ذو الحدين، الهندسي، بواسون، الأسي، الطبيعي.

لكل توزيع: **قصة ← تجربة بصرية ← تفسير القانون ← مثال محلول ← بطاقة ← اختبار قصير**.
وفي الموقع أيضًا: تدريب «أي توزيع أختار؟» (11 موقفًا)، وبطاقات مراجعة من الذاكرة قابلة للطباعة، وخريطة علاقات، وصفحة «المراجع والمنهج».

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev        # خادم تطوير
npm test           # اختبارات الحسابات واتساق المحتوى
npm run build      # فحص الأنواع + بناء النسخة النهائية في dist/
npm run preview    # معاينة النسخة النهائية
```

## النشر على GitHub Pages

المشروع جاهز للنشر عبر GitHub Actions (`.github/workflows/deploy.yml`): يشغّل الاختبارات ثم يبني الموقع وينشره.

خطوة واحدة مطلوبة من صاحب المستودع (مرة واحدة):

1. افتح المستودع على GitHub ← **Settings** ← **Pages**.
2. في **Build and deployment** اختر **Source: GitHub Actions**.
3. أعد تشغيل آخر عملية من تبويب **Actions** (أو ادفع أي تعديل).

يظهر الرابط بعدها في صفحة Pages، وعادةً يكون على الشكل `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.

ملاحظات تقنية:
- `base: './'` في `vite.config.ts` يجعل الموقع يعمل تحت أي مسار مستودع دون تعديل.
- التوجيه بالـ hash (`#/d/binomial`)، فالروابط المباشرة لا تعطي صفحة 404.
- لا خوادم ولا تحليلات ولا تسجيل دخول. التقدم يُحفظ في `localStorage` على جهاز الطالب فقط، مع زر لمسحه.

## بنية المشروع

```
src/
  lib/dist.ts            الحسابات (PMF/PDF/CDF، المتوسط، التباين، المحاكاة)
  lib/dist.test.ts       اختبارات الحسابات واتساق المحتوى
  lib/ranges.ts          نطاقات المنزلقات (تمنع الحالات غير المعرّفة)
  content/               المحتوى التعليمي منفصلًا عن العرض
  components/            المعادلات (KaTeX)، الرسوم (SVG)، المختبرات، الأقسام
  pages/pages.tsx        الصفحات
```
