# حكاية توزيع

> افهم الحكاية… يثبت القانون.

موقع عربي تفاعلي لطلاب المقررات الجامعية التمهيدية في الاحتمالات والإحصاء: ستة توزيعات احتمالية (برنولي، ذو الحدين، بواسون، الأسي، الهندسي، الطبيعي) في رحلة واحدة.

**الموقع:** https://tgtdsmy2yc-maker.github.io/hikayat-tawzee/

## ماذا فيه؟

- **شجرة العائلة** في الصفحة الرئيسية: علاقات منطقية (لا تاريخية) بين التوزيعات؛ الخط المتصل علاقة دقيقة، والمتقطع نهاية أو تقريب مكتوب معه شرطه.
- **ستة فصول**، لكل فصل حكاية تاريخية حقيقية موثقة وخمسة مشاهد:
  1. الحكاية: من أين جاء التوزيع ولماذا (كل جملة بمصدر).
  2. جرّب: أداة تحكم واحدة (مثل مطابقة بواسون على بيانات ركلات الخيل الحقيقية).
  3. ابنِ القانون: كل جزء من القانون يُبنى من الحكاية، مع «توقّع قبل أن تكشف».
  4. مسألة الاختبار: مسألة من الحكاية وأخرى بصيغة المقرر، و«حيل الحساب».
  5. ثبّت: «املأ القانون من ذاكرتك»، وأسئلة استرجاع، وجسر إلى الفصل التالي.
- **ليلة الاختبار**: الستة في جدول واحد، ومخطط قرار لتحديد التوزيع من نص المسألة، و«التوائم» التي يُخلط بينها. قابلة للطباعة.
- **تدريب مختلط**: مسائل من الستة بثلاث خطوات (أي توزيع؟ ← المعلمات ← الحساب)، ووضع «راجع اليوم».
- **أي توزيع أختار؟** و**بطاقات المراجعة** و**المراجع والمنهج**.

لا تسجيل دخول ولا تتبع ولا خوادم. التقدم محفوظ في متصفح الطالب على جهازه فقط، مع زر لمسحه.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev        # خادم تطوير
npm test           # اختبارات الحسابات والمحتوى والمصادر
npm run build      # فحص الأنواع + بناء النسخة النهائية في dist/
npm run preview    # معاينة النسخة النهائية على المنفذ 4173
npm run check:ui   # فحص الواجهة في متصفح (يتطلب Playwright والمعاينة تعمل)
```

الاختبارات تتحقق من: صحة القوانين والمتوسطات والتباينات، وأن كل رقم في الأمثلة والأسئلة يطابق الحساب، وأن كل جملة تاريخية تحمل مصدرًا مسجلًا، وحدود طول الحكايات، وتباين الألوان.
فحص الواجهة يتحقق على عرضي 390 و1440 من: عدم الخروج عن الشاشة، وعدم قص المعادلات، وطول المشاهد على الجوال، وتداخل الشجرة، وسلوك لوحة المفاتيح والتركيز.

## النشر على GitHub Pages

النشر تلقائي عبر GitHub Actions (`.github/workflows/deploy.yml`) عند كل دفع إلى الفرع: اختبارات ← بناء ← نشر.
إعداد لمرة واحدة (تم): Settings ← Pages ← Source: **GitHub Actions**. ولا تضغط Configure على أي قالب مقترح هناك.

- `base: './'` في `vite.config.ts` يجعل الموقع يعمل تحت أي اسم مستودع.
- التوجيه بالـ hash (`#/d/poisson/3`)، فالروابط المباشرة لا تعطي 404.

## بنية المشروع

```
src/
  lib/dist.ts                 الحسابات والمحاكاة (+ dist.test.ts)
  lib/compose.ts              تصحيح «املأ القانون» (+ اختبار)
  content/chapters/*.ts       الفصول الستة (المحتوى فقط)
  content/sources.ts          سجل المصادر
  content/family.ts           أسهم الشجرة وشروطها
  content/decision.ts         مخطط القرار (مصدر واحد للصفحة والتدريب)
  content/drill.ts, twins.ts  التدريب المختلط والتوائم
  components/scenes/          قالب الفصل: المشاهد والرسوم والتجارب
  pages/                      الصفحات
scripts/ui-check.cjs          فحص الواجهة
```

## المنهج

المحتوى مكتوب بصياغة أصلية. الحكايات تاريخية موثقة، وأمثلة «بصيغة المقرر» تعليمية مصطنعة ومعلنة. جرى التحقق من المصادر عبر نتائج البحث ومقتطفاته، لا بقراءة النصوص الأصلية كاملة؛ ويُنصح بمراجعة مختص قبل الاعتماد الرسمي. راجع المحتوى مجلس من ثلاث مراجعات مستقلة (طالب، أستاذ، مطوّر) قبل النشر.
